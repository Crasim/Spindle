Install Browser Link in {{browser}}

{{staging}} Use the browser profile that has the tabs you want to share.

  1. Open Manage extensions from your browser’s Extensions menu, or paste this address into a new tab.
    {{address}}
  2. Turn on Developer mode, then click Load unpacked.
  3. Select the extracted Browser Link folder. You can also paste this path into the folder chooser and choose Select Folder.
    {{folder}}
Need a fresh copy of Browser Link?

Download Browser Link ZIP. Extract it in Downloads and select the folder containing manifest.json in Load unpacked.

If Browser Link is already installed and enabled, return to Spindle to check the connection.
